# Terraform STACKIT MongoDB Flex module

Terraform module which provisions a [STACKIT MongoDB](https://registry.terraform.io/providers/stackitcloud/stackit/latest/docs/resources/mongodbflex_instance) Flex instance and its users on [STACKIT](https://www.stackit.de/en/).

This repository is not from the official STACKIT organization.

> **Naming.** The repository is `terraform-stackit-flex-mongodb` (readability), while the provider
> resources are `stackit_mongodbflex_instance` / `stackit_mongodbflex_user`.

## Usage

```hcl
module "flex_mongodb" {
  source  = "terraform-stackit-modules/flex-mongodb/stackit"
  version = ">= 1.0.0"

  project_id      = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  name            = "app-mongodb"
  mongodb_version = "7.0"
  acl             = ["0.0.0.0/0"]
  replicas        = 1
  backup_schedule = "0 0 * * *"

  flavor  = { cpu = 1, ram = 4 }
  storage = { class = "premium-perf2-mongodb", size = 10 }

  options = {
    type                       = "Single"
    point_in_time_window_hours = 30
    snapshot_retention_days    = 3
  }

  users = {
    app = {
      username = "app_user"
      database = "app_db"
      roles    = ["readWrite"]
    }
  }
}
```

## Composite module

- `modules/instance` — the `stackit_mongodbflex_instance` (toggled by `create_instance`).
- `modules/user` — `stackit_mongodbflex_user` entries (`for_each` over `users`).

The root wires them together and, when `create_instance = false`, targets an existing instance via
`instance_id` for user management.

## Examples

- [`basic`](./examples/basic) — minimal single-node instance + one user.
- [`complete`](./examples/complete) — prod-like: restricted ACL, larger flavor/storage, extended
  backup retentions, multiple users (read-write + read-only).
- [`replica`](./examples/replica) — a native **replica set** (`options.type = "Replica"`,
  `replicas = 3`). Unlike the SQL Flex engines, MongoDB Flex exposes replication natively rather
  than via the plan/flavor.

## Notes

- Generated user passwords/URIs are exposed via **sensitive** outputs.
- `users` is a map keyed by a **stable identifier**; the instance\_id (known after apply when the
  instance is created here) is only a resource attribute, never a `for_each` key.
- `options.type` is validated against `Single` / `Replica` / `Sharded`.

## Terratest

The `test/` directory holds Terratest integration tests that apply the example root modules against a real STACKIT project (requires `STACKIT_SERVICE_ACCOUNT_KEY` and `STACKIT_PROJECT_ID`). Only the `basic` example runs in CI; `complete`/`replica` self-skip unless `TERRATEST_RUN_ALL` is set.

```bash
cd test
go mod init github.com/terraform-stackit-modules/terraform-stackit-flex-mongodb
go get github.com/gruntwork-io/terratest@v1.0.1
go mod tidy
TERRATEST_RUN_ALL=1 go test -v -timeout 90m ./...
```
